# 网络安全学习路径与知识体系

本文面向网络安全初学者, 给出系统化的学习路线与知识地图, 所有内容仅用于合法防御性学习与授权测试场景。

## 一、基础阶段

1. **计算机网络**: TCP/IP 协议栈、HTTP/HTTPS、DNS、常用端口与协议分析。推荐使用 Wireshark 抓包观察真实流量。
2. **操作系统**: Linux 常用命令、权限模型、进程与服务管理; Windows 域基础。
3. **Web 基础**: HTML/CSS/JavaScript、浏览器同源策略、Cookie 与会话机制、前后端分离架构。
4. **一门编程语言**: Python(脚本与自动化)、Java/Go(理解企业应用)任选其一深入。

## 二、Web 安全核心

按漏洞原理逐个学习, 每个漏洞掌握"原理 → 触发条件 → 防御":

- SQL 注入、XSS、CSRF、SSRF、路径穿越、命令注入
- 文件上传漏洞、反序列化漏洞、逻辑漏洞(越权/支付)
- 参考体系: OWASP Top 10、OWASP API Security Top 10、CWE 分类

实验环境: 仅在本地搭建的靶场(如 DVWA、Pikachu、自建虚拟机)中练习, 未经授权严禁对真实目标测试。

## 三、安全工具

- Burp Suite: Web 代理与请求重放, 理解请求/响应流程
- Nmap: 端口与服务识别(仅授权资产)
- SQLMap: 注入验证(仅授权)
- Wireshark: 流量分析
- Metasploit: 渗透框架(授权测试)

原则: 先理解原理再学工具, 工具只是自动化手段。

## 四、进阶方向

1. **内网与后渗透**: 域环境、横向移动、权限维持(授权红队场景)
2. **安全开发**: 代码审计、SDLC、威胁建模、SAST/DAST/SCA
3. **密码学应用**: 证书体系、TLS 握手、哈希与加密正确使用
4. **云安全**: IAM 最小权限、云配置审计、容器安全
5. **AI 安全**: 提示注入、数据投毒、RAG 系统安全、模型供应链

## 五、法律法规与职业道德

- 遵守《网络安全法》《数据安全法》《个人信息保护法》等法律法规
- 未授权测试即违法: 扫描、爆破、注入真实网站都可能触法
- 发现漏洞应通过官方 SRC/CNVD 等合规渠道报告
- 职业道德: 授权范围内工作、最小影响、保护数据、及时报告

## 六、学习方法建议

1. 建立知识体系图, 按图学习而非碎片化刷教程
2. 每学一个漏洞, 动手"复现(靶场)→修复(写代码)→总结(写笔记)"
3. 阅读 CVE 与真实漏洞报告, 理解漏洞生命周期
4. 参与 CTF 比赛(Web/Crypto 方向)巩固技能
5. 关注公开知识库: OWASP、MITRE CWE/ATT&CK、权威厂商安全博客
