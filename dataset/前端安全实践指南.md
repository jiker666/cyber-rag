# 前端安全实践指南

## 前端特有的攻击面

前端代码运行在用户浏览器中, 天然"开源", 攻击面包括: XSS、依赖链攻击、敏感信息泄露、客户端逻辑绕过、点击劫持等。

## XSS 防御(前端视角)

1. **框架默认转义**: Vue `{{ }}`、React JSX 会转义插值, 是安全基线
2. **危险 API 警惕清单**: `v-html`、`innerHTML`、`outerHTML`、`insertAdjacentHTML`、`document.write`、`eval`、`new Function`、`setTimeout("字符串")`
3. 必须渲染用户富文本时, 使用 DOMPurify 白名单净化:

```javascript
import DOMPurify from 'dompurify'
div.innerHTML = DOMPurify.sanitize(userHtml, {
  ALLOWED_TAGS: ['b', 'i', 'em', 'strong', 'a', 'p', 'br'],
  ALLOWED_ATTR: ['href']
})
```

4. URL 跳转校验协议与域名, 防止 `javascript:` 伪协议与开放重定向:

```javascript
function safeRedirect(url) {
  const u = new URL(url, location.origin)
  if (u.origin !== location.origin) throw new Error('非法跳转')
  location.href = u.href
}
```

## 凭证存储策略

| 方案 | 抗 XSS | 抗 CSRF | 建议 |
|------|--------|---------|------|
| localStorage | 否 | 是 | 需严格 XSS 防御, 短有效期 |
| 内存(JS 变量) | 较强 | 是 | 刷新丢失, 需静默续期 |
| HttpOnly Cookie | 强 | 需防御 | 配 SameSite |

要点:

- Token 过期即清除, 登出调用服务端失效接口
- 严禁在前端代码、构建产物中保存任何 API Key/Secret —— 前端的一切均可被提取
- Source Map 生产环境不上传到公开 CDN

## 依赖供应链安全

1. 锁定版本与完整性: `npm ci` + lockfile 提交仓库
2. 持续审计: `npm audit`, 高危依赖及时升级
3. 谨慎引入维护停滞的包, 警惕 typosquatting(拼写仿冒)包名
4. CI 中做许可证与 SBOM 检查

## CSP 与构建

- 配合后端设置 CSP, 前端构建产物避免 inline script, 或使用 nonce
- 第三方脚本(SDK/统计)必须评估其必要性, 从可信 CDN 引入并锁定版本

## 其他实践

- 敏感信息展示默认脱敏, 展开/复制需二次交互并留痕
- 错误提示不回显后端堆栈与内部接口地址
- 前端校验仅为体验优化, 安全校验必须在服务端重复执行
- 防点击劫持由响应头承担, 前端可叠加 `if (window.top !== window.self) top.location = self.location`
