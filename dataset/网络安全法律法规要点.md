# 网络安全法律法规与合规要点

## 我国核心法律体系

### 《网络安全法》(2017 施行)

- 网络运营者的安全保护义务: 等级保护制度、应急处置、漏洞处置
- 关键信息基础设施(CII)重点保护
- 个人信息保护的基本要求(合法、正当、必要)

### 《数据安全法》(2021 施行)

- 数据分类分级保护
- 重要数据目录与风险评估
- 数据交易中介义务、跨境传输要求

### 《个人信息保护法》(2021 施行)

- 处理个人信息需具备合法性基础(同意/合同履行/法定义务等)
- 最小必要原则: 不得过度收集
- 敏感个人信息(生物识别、宗教信仰、行踪、医疗健康、金融账户、不满十四周岁未成年人信息)需单独同意
- 个人权利: 知情、查阅、复制、更正、删除、可携带、自动化决策拒绝权

### 《刑法》相关罪名

- 第 285 条: 非法侵入计算机信息系统罪; 非法获取计算机信息系统数据、非法控制罪
- 第 286 条: 破坏计算机信息系统罪
- 第 287 条: 利用计算机实施犯罪的提示性规定; 帮助信息网络犯罪活动罪(第 287 条之二)
- 未经授权对真实系统进行扫描、爆破、注入、拖库均可能构成犯罪, 与是否"造成实际损失"无关

## 渗透测试合规边界

1. **书面授权是前提**: 授权书需明确范围、时间窗口、方法限制、数据处理、应急联络
2. 超出授权范围即失去法律保护
3. 发现漏洞: 按约定报告, 不得留存、扩散或交易漏洞数据
4. 测试数据: 使用脱敏/虚构数据, 不得下载真实用户数据"顺手"保存

## 合规披露渠道

- 企业 SRC(安全应急响应中心)
- CNVD(国家信息安全漏洞共享平台)、CNNVD(国家信息安全漏洞库)
- 报告内容: 影响范围、复现步骤、危害评估、修复建议

## 开发者合规清单

- [ ] 收集个人信息前有隐私政策并取得同意
- [ ] 收集字段与业务目的直接相关(最小必要)
- [ ] 敏感数据传输与存储加密
- [ ] 提供账号注销与数据删除能力
- [ ] 数据出境场景完成安全评估或标准合同备案
- [ ] 等级保护定级备案与测评(按系统等级)
