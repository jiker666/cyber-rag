# 邮件安全与钓鱼防护

## 邮件协议与安全增强

| 协议 | 作用 |
|------|------|
| SPF | 声明哪些服务器可代表本域发信, 拒绝伪造来源 |
| DKIM | 邮件签名, 保证内容传输中不被篡改 |
| DMARC | 策略声明(SPF/DKIM 失败如何处置)+ 报告反馈 |

三者配合可显著遏制域名伪造与商业邮件诈骗(BEC)。

## 钓鱼邮件的常见形态

1. **凭证钓鱼**: 仿造登录页(如"密码即将过期"), 诱导输入账号密码
2. **附件恶意**: 宏文档、漏洞利用文档(如历史 CVE 的 Office 漏洞)、伪装的 exe/scr
3. **链接劫持**: 短链/开放重定向跳转钓鱼站、同形异义域名(g00gle.com)
4. **商业欺诈**: 冒充高管/财务要求紧急转账(无链接无附件, 纯社工)
5. **MFA 疲劳攻击**: 已有密码后反复推送 MFA 请求, 诱导误按同意

## 识别要点(用户侧)

- 发件域名仔细核对(含相似字符替换)
- 制造紧迫感("立即""否则封号")是典型话术
- 悬停查看链接真实目标再点击
- 附件类型警惕: .docm、.exe、.js、.vbs、.lnk、压缩包内可执行文件
- 涉及转账/改密/审批, 通过第二渠道(电话)核实

## 技术防护(企业侧)

1. **网关过滤**: 附件类型黑白名单、沙箱 detonation、URL 信誉与重写
2. **SPF/DKIM/DMARC 全量配置**, DMARC 逐步收紧到 p=reject
3. **隔离策略**: 检测到恶意进隔离区而非垃圾箱, 降低误点概率
4. **外部邮件标识**: 给来自域外的邮件加醒目标记, 防冒充内部高管
5. **条件访问**: 异常地域/设备登录邮件账号触发 MFA
6. **演练**: 定期模拟钓鱼统计点击率, 对高点击人群靶向培训

## 事件响应

员工点击并输入凭证后:

1. 立即改密 + 吊销活动会话 Token
2. 检查邮箱转发规则与 OAuth 授权(攻击者常留后门)
3. 溯源邮件, 网关全网撤回同源邮件
4. 排查账号登录日志, 评估数据访问范围
5. 复盘并优化检测规则
