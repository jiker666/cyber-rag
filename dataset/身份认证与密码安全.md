# 身份认证与密码安全实践

## 密码存储的演进

| 方案 | 安全性 | 说明 |
|------|--------|------|
| 明文 | 危险 | 任何泄露即直接暴露 |
| MD5/SHA1 | 危险 | 快速哈希, 彩虹表与暴力破解极易 |
| 加盐 MD5 | 不足 | 盐可被一同拖库, GPU 每秒可算数十亿次 |
| PBKDF2/BCrypt/Argon2 | 推荐 | 自适应慢哈希+盐, 成本参数可随硬件升级 |

## BCrypt 原理

BCrypt 基于 Blowfish 改造, 核心特点:

1. **自带随机盐**: 相同密码每次哈希结果不同, 天然抗彩虹表
2. **成本因子**: 哈希轮数为 2^cost, 可随硬件进步调大, 保持破解成本
3. **输出自包含**: `$2a$10$N9qo8uLOickgx2ZMRZoMye...` 内含算法版本、成本因子、盐与哈希值, 校验时直接从串中解析, 无需单独存盐

推荐成本因子为 10-12(每次哈希约 60-250ms)。

## 登录流程安全

1. **防用户枚举**: 登录失败统一提示"用户名或密码错误"
2. **防爆破**: 失败计数 + 锁定/验证码/限流(如 5 次失败锁定 15 分钟)
3. **传输安全**: 全程 HTTPS, 禁止明文 HTTP
4. **会话安全**: 登录成功后重置会话 ID, Token 具备过期时间
5. **多因素认证**: 高安全场景叠加 TOTP/短信/硬件密钥

## 会话与凭证管理

- 密码、Token、API Key 只在内存与安全存储中出现, 不写日志、不进前端持久化
- API Key 通过环境变量或密钥管理服务注入, 定期轮换
- 注销与改密后使既有凭证失效
- 凭证泄露响应: 立即吊销、强制改密、审计异常访问

## 弱密码治理

- 长度 ≥ 8 并检查常见弱密码字典
- 建议使用密码短语或密码管理器
- 不与其他站点复用密码
