# 恶意代码与病毒防护基础

## 恶意代码分类

| 类型 | 特征 | 典型行为 |
|------|------|---------|
| 病毒 | 依附宿主文件, 需人工触发 | 感染可执行文件 |
| 蠕虫 | 自我复制, 网络传播 | 主动扫描漏洞扩散 |
| 木马 | 伪装成正常程序 | 窃取数据、开后门 |
| 勒索软件 | 加密文件索要赎金 | 加密+勒索+横向传播 |
| 间谍软件 | 隐蔽收集信息 | 键盘记录、截屏 |
| Rootkit | 深层隐藏自身 | 内核级隐藏进程/网络 |

## 传播途径

1. 邮件附件与钓鱼链接(最主要入口)
2. 捆绑安装与盗版软件
3. 漏洞利用(未打补丁的公网服务、RDP 弱口令)
4. U 盘等移动介质自动运行
5. 恶意广告与被入侵的正规网站

## 常见防护措施

### 终端层

- 安装并保持更新的杀毒/EDR 软件
- 操作系统与第三方软件及时补丁(浏览器、Office、输入法常被利用)
- 禁用 Office 宏默认执行, 警惕"启用内容"提示
- 最小化安装, 关闭不必要的服务与端口

### 网络层

- 邮件网关过滤附件类型与钓鱼链接
- DNS 过滤拦截恶意域名
- 出口流量审计, 发现异常外联
- 微分段限制横向移动

### 管理层

- 最小权限 + 禁用日常使用管理员账户
- 3-2-1 备份(见漏洞管理与应急响应), 定期恢复演练
- 安全意识培训: 识别钓鱼、不下载不明来源文件
- U 盘管控与外来设备准入

## 勒索软件防护要点

1. 备份隔离是最后防线: 离线/不可变存储, 否则备份同样被加密
2. 关闭 RDP 直接公网暴露, 使用 VPN + MFA
3. 高危漏洞及时修补(勒索家族大量利用历史 N-day)
4. 中招后处置: 隔离 → 取证 → 从备份恢复 → 评估泄露(双重勒索), 不建议私下支付赎金

## 分析环境(仅供学习)

恶意代码动态分析必须在隔离环境:

- 断网虚拟机 + 快照恢复, 或专用沙箱
- 分析工具: 行为监控、网络模拟、注册表/文件变化比对
- 切勿在个人电脑或生产环境直接运行样本
